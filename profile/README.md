### How it works

1. **You ask.** Tell the agent that can read your code what to diagram.
2. **The agent draws.** It writes diagram source, saves it beside your code and publishes a diagram your team can see.
3. **Your team reviews.** Pin comments to the exact box or arrow that needs to change.
4. **The agent updates.** It reads the open comments, revises the source and replies to each thread.

Every save is a new version, so the history shows what changed and why.

### Connect your agent

EasyDiagram speaks [MCP](https://modelcontextprotocol.io). With Claude Code, for example:

```bash
claude mcp add --transport http easydiagram https://app.easydiagram.io/mcp
```

There is no token to paste: the first time, your browser opens to sign in, pick a team and allow the agent.
